# WiFi Scanner

PWA to measure WiFi signal strength and find optimal reception locations.

## Features
- Real-time signal strength visualization
- Distance estimation
- Automatic scanning
- Works on any WiFi network
- Offline-capable

## Usage
1. Open `https://your-domain/wifi-scanner/`
2. Install as app (menu → Install)
3. Tap "Scan Now" or move around to see signal changes

## Perfect for
- Finding best router placement
- Locating WiFi dead zones
- Choosing best spots for outdoor activities
- Setting up WiFi extenders

## Browser Support
Chrome/Edge (Android 5+), Firefox (limited), Safari (iOS 13+)
