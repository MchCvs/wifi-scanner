# WiFi Scanner PWA

Application web progressive pour mesurer la force du signal WiFi et trouver les meilleurs emplacements de réception.

## Fonctionnalités
- Visualisation en temps réel de la force du signal
- Estimation de la distance par rapport au routeur
- Analyse automatique du réseau
- Fonctionne sur tout réseau WiFi
- Mode hors ligne disponible

## Utilisation
1. Ouvrez l'URL dans votre navigateur
2. Installez l'application (menu → Installer)
3. Appuyez sur "Analyser maintenant"
