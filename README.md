# WiFi Scanner

Real-time WiFi quality measurement and house mapping. Find the best WiFi spots in your home.

## Features
- **Live Signal Quality** : Speed (Mb/s) + Latency (ms)
- **Continuous Scanning** : Auto-scan every 5 seconds
- **House Map** : Color-coded rooms (Green=Good, Orange=Fair, Red=Poor)
- **Data Persistence** : Results saved locally

## How to Use
1. Open https://mchcvs.github.io/wifi-scanner/
2. Select your current room
3. Tap **Start Continuous Scan**
4. Move around your house - quality updates automatically
5. View house map to find best WiFi locations

## Perfect For
- Finding optimal router placement
- Choosing best spot for WiFi extender
- Mapping WiFi dead zones
- Testing signal in different rooms

## How It Works
- **Speed** : Downloads test file, measures Mb/s
- **Latency** : Pings Google, measures response time
- **Quality** : 60% speed + 40% latency score
- **Map** : Stores room quality in browser storage

## Browser Support
Chrome, Edge, Samsung Internet (Android 5+)
